# Portfólio Pessoal

Portfólio online de **Fernanda Calvi de Barros**, desenvolvido para apresentar minha trajetória, formação acadêmica, tecnologias, projetos e canais de contato.

O projeto foi criado como atividade prática da disciplina **Fundamentos da Programação Web**, do curso de Sistemas de Informação da UNINTER.

## Acesso ao projeto

- Site publicado: [fernandacalvi.github.io/portfolio](https://fernandacalvi.github.io/portfolio/)
- Repositório: [github.com/FernandaCalvi/portfolio](https://github.com/FernandaCalvi/portfolio)

## Tecnologias utilizadas

- HTML5
- CSS3
- JavaScript puro

O projeto não utiliza frameworks ou bibliotecas de CSS e JavaScript.

## Funcionalidades

- Navegação entre as seções por âncoras
- Layout responsivo para computadores, tablets e celulares
- Menu adaptado para dispositivos móveis
- Alternância entre tema claro e escuro
- Preferência de tema armazenada no navegador
- Apresentação de formação, tecnologias e projeto acadêmico
- Links para redes profissionais
- Formulário de contato com validação em JavaScript
- Simulação de envio com mensagens de sucesso e erro
- Ano do rodapé atualizado automaticamente

## Seções do portfólio

- **Início:** apresentação profissional e áreas de interesse
- **Sobre:** trajetória, objetivos, tecnologias e interesses pessoais
- **Formação:** graduação, cursos, certificações e idiomas
- **Projetos:** apresentação do portfólio como projeto acadêmico
- **Contato:** links profissionais e formulário validado com JavaScript

## Contexto acadêmico

Este portfólio atende aos requisitos da atividade prática de Fundamentos da Programação Web, utilizando HTML5 semântico, CSS3 sem frameworks e JavaScript puro.
